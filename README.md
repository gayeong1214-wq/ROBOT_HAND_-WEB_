# HANDSLab — A world of robotic hands

영남대학교 HANDS Lab의 로봇핸드 아카이브입니다. 전 세계 로봇핸드를 **실제 제품 사진과 사양**으로 한곳에서 조사하고 비교할 수 있습니다.
HANDSLab 노션 조사표(「지구상의 로봇핸드 조사」, 99건)와 기존 사이트 자료의 ARTUS Lite를 합쳐 **총 100개 모델**을 옮겼고, 조사표에 없던 값은 제조사 제품 페이지에서 보충했습니다. 어디에도 없는 값은 `미확인`으로 둡니다.

- 사이트 주소: <https://gayeong1214-wq.github.io/ROBOT_HAND_-WEB_/>
- 빌드 도구 없이 `index.html`만 열면 동작합니다(정적 HTML · CSS · JavaScript).

## 화면 구성 (2026-11 리디자인)

| 영역 | 내용 |
| --- | --- |
| Header | 로고와 메뉴(Wiki · Graphical · Contact). Wiki는 전체 목록 표, Graphical은 사진 카드로 바로 이동. 860px 미만에서는 햄버거 메뉴. |
| 첫 화면 · Interactive Gallery | **곡면 격자 3D 갤러리**가 화면 전체를 채우고, 왼쪽 아래에 큰 제목 "A world of robotic hands."와 버튼, 오른쪽 아래에 모델·제조사·국가 수. 끌기 · 관성 · 마우스 3D 패럴랙스 · 확대 효과 · 크게 보기(상세 정보, 제품/구매 링크). |
| 웹사이트 설명 | 이 아카이브가 무엇인지와 검색·비교할 수 있는 로봇핸드 수(총 100개)·제조사·국가·구매 링크 수. 숫자는 데이터에서 자동으로 채웁니다. |
| Robot Hands | 기존 탐색 기능: 전체 목록 표 / 사진 카드, 검색·필터·정렬, 최대 4개 비교, 상세 화면. 휴대폰(639px 이하)에서는 넓은 표 대신 사진·모델·제조사·핵심 사양(손가락·DoF·무게)을 한 줄씩 보여 주는 목록으로 바뀌고, 누르면 상세 화면이 열립니다. |
| Contact | 책임교수, 위치(지도 링크), 전화, 연구실 링크, 저작권 표기. |

상세 화면에는 노션 원문을 따로 보여 주지 않고, `링크`에는 **제품 링크**(노션 '대표사이트')와 **구매 링크**(공식 스토어 · 구매 문의 · 판매처)만 둡니다. 표와 비교 화면에도 같은 두 열이 있습니다.

## 디자인

- 배경은 스크롤에 따라 **남색(#050B20) → 흰색**으로 서서히 바뀝니다(첫 화면 남색, 웹사이트 설명을 지나며 밝아지고 로봇핸드 목록부터 흰색). 배경 밝기에 맞춰 글자색도 바뀝니다.
- 큰 제목은 영어, 본문은 한국어. 테두리·그림자·장식은 최소로.
- 글꼴: [SUIT Variable](https://github.com/sun-typeface/SUIT) (SIL OFL 1.1) — jsDelivr에서 불러옵니다.
- 참고: Framer Marketplace의 'Gallery X' 컴포넌트에서 **곡면 격자 · 끌기 · 관성** 같은 상호작용 원리만 참고했고, 코드와 디자인은 외부 라이브러리 없이 이 프로젝트에서 새로 만들었습니다(CSS 3D transform + JavaScript).

## Interactive Gallery 동작 (`assets/js/gallery.js`)

- 격자의 각 칸 위치를 매 프레임 계산해 구면(가운데가 가깝고 가장자리가 멀어지는 면) 위 3D 좌표로 바꿉니다. 화면 밖 칸은 그리지 않습니다.
- 끌기: 마우스는 모든 방향, 터치는 가로로(세로로 밀면 페이지 스크롤). 놓으면 관성으로 감속하고, 멈췄다 놓으면 바로 멈춥니다.
- 가만히 두면 1초에 약 12px로 아주 느리게 흐르고, 마우스를 올리거나 조작하면 멈춥니다. 화면 밖에 있으면 계산도 멈춥니다.
- 키보드: 갤러리에 초점을 두고 화살표로 한 칸씩, Tab으로 사진 이동(초점 간 사진이 가운데로 옴), Enter로 크게 보기, 크게 보기에서 ←/→, Esc.
- 사진은 화면에 처음 들어올 때만 불러옵니다(lazy loading).
- `움직임 줄이기` 설정: 흐름 · 관성 · 패럴랙스 · 전환 효과를 끄고 끌기만 남깁니다.
- 화면 폭에 따라 칸 크기(PC 약 190–244px · 태블릿 168px · 휴대폰 128px), 간격, 곡률이 자동으로 바뀝니다.

### 갤러리에 연구·실험·연구실 사진 넣기

`assets/data/gallery-extra.js`의 목록에 사진을 한 줄씩 추가하면 제품 사진 사이에 고르게 섞이고, 갤러리 위에 분류 버튼(전체 · 로봇핸드 · 연구 · 실험 · 연구실)이 나타납니다. 형식은 파일 안 주석을 보세요.

## 데이터 기준

- 원본: `data/source/handslab-public-data.json` — 노션 조사표의 모델 99건 + ARTUS Lite(Sarcomere Dynamics, 노션에는 없고 기존 사이트 자료에 있던 모델) = 100건. 내부 견적·가격·조사자 정보는 넣지 않습니다(가격은 사이트 어디에도 싣지 않습니다).
- 숫자 사양은 `tools/build_data.py`의 `EXTRA`, 나머지 특징은 `data/features.json`에 있습니다. 둘 다 노션 문장에 적힌 내용만 옮깁니다.
- 노션에 없던 칸은 각 제품의 공식 제품 페이지·데이터시트에서 보충했습니다(`data/web_specs.json`, 85개 모델 377칸). 노션 값이 있는 칸은 덮어쓰지 않습니다. 표 칸에 맞지 않는 사양(전원, IP 등급, 반복정밀도, 크기 등)은 ‘기타 사양’ 열에 둡니다.
- 구매 링크(`data/buy_links.json`, 84개 모델, 2026-11-23 수집): 제조사 공식 스토어 상품 페이지(store) → 제조사 공식 구매·견적 문의(quote) → 공식/전문 판매처의 같은 모델 상품 페이지(retailer) 순서로 찾았습니다. 연구용·단종·비매품이라 판매처가 없는 15개 모델은 `판매처 없음`으로 표시합니다. 개인 판매자·블로그·정리 사이트는 쓰지 않았습니다.

데이터를 고친 뒤에는 다음 명령으로 사이트용 파일을 다시 만듭니다.

```bash
python3 tools/build_data.py
```

## 사진 출처와 이용 원칙

- 사진은 노션 조사표에 첨부된 제품 사진(모델당 1장)이며, 저작권은 각 제조사·연구기관에 있습니다. 2F-85는 HANDSLab이 따로 받은 Robotiq 제품 사진입니다.
- 사진 카드와 크게 보기에서 사진 아래에 제조사(기관)명과 제품 페이지 링크를 표시합니다.
- 비영리 연구·교육 목적의 비교 자료로서 출처를 밝혀 인용하는 형태입니다(저작권법 제28조, 제37조). 권리자가 요청하면 즉시 내립니다(페이지 맨 아래 ‘삭제 요청’ → GitHub Issues).
- 상업적 이용으로 바뀌면 제조사 보도자료 이미지를 쓰거나 사용 허락을 받으세요.
